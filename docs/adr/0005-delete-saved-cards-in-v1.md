# ADR 0005: 保存済み名刺の削除を v1 に含める

## Status

- Accepted

## Decision Drivers

- 間違えて確定した名刺を取り除く手段が要る
- 編集機能がない前提でも、削除だけは利用者の回復手段として必要
- フォルダ側の原本は tansu の管理外であり、アプリの都合で消してはならない

## Context

確定済みの名刺を消す操作は、承認済み計画の AC1–AC25 に合格条件がなかった。候補を全て外したときに複製を削除する経路（AC17）はあるが、保存済みの名刺を画像詳細から削除する操作は未定義だった。

削除の対象はアプリ内に保持する名刺と複製であり、利用者のフォルダにある原本ファイルではない。

## Options Considered

- 削除を v1 に入れ、合格条件として AC26 を追加する
- 削除を v1 から外し、画像詳細は表示と共有だけにする

## Decision

- 保存済み名刺の削除を v1 に含める。画像詳細から削除できる
- AC26 を追加する: 詳細画面で削除 → 名刺 0 件 → 複製も削除、原本は残る
- その名刺画像から確定した名刺が 0 件になったら、アプリ内の複製も削除する
- フォルダ側の原本ファイルは削除しない

## Consequences

- Positive: 誤って確定した名刺を利用者が自分で回復できる
- Positive: 参照されなくなった複製が残り続けない
- Negative: 削除の確認 UI と、AC26 の検証（原本が残ることの確認）が追加で必要になる

## Adoption and Exceptions

- 原本ファイルを削除する変更を加えない
- 削除を取り消す（ゴミ箱や復元）機能を足す場合は、新しい ADR で扱う
